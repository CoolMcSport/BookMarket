BOOKMARKET — ЗАПУСК НА WINDOWS

1. Распакуйте архив в отдельную папку.
2. Откройте эту папку в Visual Studio Code.
3. Откройте Терминал -> Новый терминал и выберите cmd.
4. Выполните:

   npm install

5. После установки выполните:

   npm start

6. Откройте в браузере:

   http://localhost:3000

Проверка списка книг:
   http://localhost:3000/books

Добавление книги:
   http://localhost:3000/add-book.html

Каталог:
   http://localhost:3000/catalog.html

Чтобы остановить сервер, щелкните по терминалу и нажмите Ctrl + C.
